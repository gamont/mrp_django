# MRP 0.5.4 — Terminal de chão de fábrica

A versão 0.5.4 adiciona um terminal touch/kiosk para execução operacional por centro de trabalho e máquina.

## Recursos

- login simplificado por crachá + PIN com PIN armazenado via hash Django;
- bloqueio temporário após cinco falhas;
- seleção de estação;
- fila de operações por centro de trabalho;
- despacho da próxima operação por prioridade operacional e data de entrega;
- início de setup, início/retomada, pausa e conclusão por toque;
- apontamento de quantidade boa, refugo, horas de operador e máquina;
- estado atual da máquina;
- registro e encerramento de paradas com motivo;
- refresh HTMX a cada 10 segundos;
- eventos imutáveis em `DomainEvent`.

## Configuração inicial

```bash
python manage.py migrate
python manage.py bootstrap_roles
python manage.py seed_shopfloor --plant SP01
python manage.py set_operator_pin --username operador --badge 1001 --pin 123456
```

Abra `/shopfloor/login/`.

## Segurança

O terminal reutiliza a sessão autenticada do Django. O PIN não é armazenado em texto puro. A permissão `shopfloor.use_shopfloor_terminal` é necessária, exceto para superusuários.
