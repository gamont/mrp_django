# MRP 0.5.7 — Manutenção industrial integrada

A versão 0.5.7 adiciona `apps.maintenance` e integra manutenção com máquinas do chão de fábrica, paradas, OEE e estoque de peças.

## Domínio

- `MaintenanceAsset`: ativo industrial, opcionalmente ligado 1:1 a `shopfloor.Machine`.
- `AssetMeterReading`: leitura de horímetro/contador.
- `MaintenancePlan`: preventiva por calendário, medidor ou estratégia híbrida.
- `MaintenanceWorkOrder`: OM preventiva, corretiva, preditiva ou inspeção.
- `MaintenancePart`: peças planejadas e emitidas para a OM.
- `FailureEvent`: falha, causa, ação corretiva e resolução.

## Integração com OEE

Ao iniciar uma OM vinculada a uma máquina:

- preventiva: máquina muda para `PREVENTIVE` e é aberta uma parada `MAINT-PREV` classificada como `PLANNED`;
- corretiva: máquina muda para `REPAIR` e é aberta uma parada `MAINT-CORR` classificada como `UNPLANNED`.

A conclusão encerra a parada e retorna a máquina para `IDLE`. Paradas corretivas entram no cálculo já existente de falhas, MTBF e MTTR.

## Planejamento preventivo

Os planos podem ser vencidos por:

- `CALENDAR`: `next_due_date`;
- `METER`: `next_due_meter` comparado à última leitura;
- `HYBRID`: primeiro critério que vencer.

Geração automática:

```bash
python manage.py generate_maintenance_orders --plant SP01
python manage.py generate_maintenance_orders --plant SP01 --through 2026-08-31
```

## Seed

```bash
python manage.py seed_maintenance --plant SP01
```

Cria um ativo para cada máquina e um plano preventivo mensal demonstrativo.

## Interface

- `/maintenance/`: dashboard, ordens abertas, falhas, planos vencidos e ativos;
- `/maintenance/orders/<id>/`: detalhes da OM, peças, falhas e leituras;
- ações HTMX: iniciar, concluir e baixar peça de reposição.

## API

- `/api/maintenance-assets/`
- `/api/maintenance-meter-readings/`
- `/api/maintenance-plans/`
- `/api/maintenance-work-orders/`
- `/api/maintenance-parts/`
- `/api/maintenance-failures/`

Ações:

- `POST /api/maintenance-assets/{id}/report-failure/`
- `POST /api/maintenance-plans/generate-orders/`
- `POST /api/maintenance-work-orders/{id}/start/`
- `POST /api/maintenance-work-orders/{id}/complete/`
- `POST /api/maintenance-parts/{id}/issue/`

## Permissões

Novo papel padrão: `MRP Manutenção`. O `bootstrap_roles` concede escrita em manutenção e as permissões necessárias de estoque e chão de fábrica.
