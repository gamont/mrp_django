# UI Operacional 0.5.2 — telas de detalhe e drill-down

A 0.5.2 acrescenta páginas operacionais de detalhe sem criar novas tabelas. O objetivo é transformar os dashboards em pontos de entrada para investigação completa de cada documento.

## Telas

- `/planner/orders/<id>/`: ordem planejada, buckets MRP, mensagens e pegging.
- `/production/orders/<id>/`: materiais, reservas, operações, apontamentos, movimentações, pegging, custos, variações e timeline.
- `/purchasing/orders/<id>/`: linhas, recebimentos, PPV e timeline.
- `/quality/inspections/<id>/`: características, resultados, NCR, disposições, lote/série e timeline.
- `/costing/items/<id>/`: composição do custo, histórico de versões, estoque, custo de OP e variações.

## Navegação

Os códigos/números principais nos dashboards da 0.5.1 agora são links para o respectivo detalhe. As telas são server-side Django e continuam compatíveis com a navegação HTMX existente.

## Banco de dados

Não há migração nova nesta versão. A 0.5.2 é uma evolução da camada de apresentação e consultas.
