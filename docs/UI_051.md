# UI Operacional 0.5.1

A versão 0.5.1 transforma os dashboards da 0.5.0 em superfícies transacionais.

## Planejamento

`POST /planner/orders/<id>/firm/` firma uma ordem MRP.
`POST /planner/orders/<id>/convert/` converte a ordem em OP ou OC usando o serviço de planejamento.

## Produção

`POST /production/orders/<id>/release/` executa a liberação e reserva de materiais.
`POST /production/orders/<id>/complete/` registra quantidade boa, refugo, local de entrada e opção de backflush.

## Compras

`POST /purchasing/lines/<id>/receive/` registra o recebimento, atualiza a linha da OC e movimenta o estoque.

## Qualidade

`POST /quality/inspections/<id>/start/` inicia a inspeção.
`POST /quality/inspections/<id>/complete/` encerra a inspeção com quantidades aprovada e rejeitada. Características obrigatórias continuam sendo validadas pelo serviço de qualidade.

## Custos

`POST /costing/periods/<id>/final-close/` executa o fechamento industrial definitivo. O checkbox de reconciliação estrita bloqueia o fechamento quando há divergência físico-financeira.

## Princípios

A UI não duplica regras de negócio. Ela chama os mesmos serviços usados pela API e comandos administrativos. Assim, locks de banco, validações, eventos de domínio e idempotência permanecem centralizados.
