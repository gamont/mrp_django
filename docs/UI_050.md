# Interface operacional 0.5.0

A versão 0.5.0 introduz uma interface server-side em Django com atualização parcial via HTMX e fallback por navegação HTTP convencional.

## Painéis

- **Planejamento:** execução MRP, mensagens de exceção, ordens planejadas e gargalos de capacidade.
- **Produção:** OPs liberadas/em andamento, atrasos e fila de operações por centro de trabalho.
- **Compras:** OCs abertas, recebimentos pendentes e entregas atrasadas.
- **Estoque:** saldos físicos, alocações e itens sem disponibilidade.
- **Qualidade:** inspeções pendentes, rejeições e não conformidades.
- **Custos:** período contábil, WIP, custos calculados e variações por OP.

## Segurança

As páginas usam a autenticação de sessão nativa do Django. O mesmo usuário/grupos utilizados pelo RBAC da API podem acessar a interface. A seleção de planta é persistida na sessão do usuário.

## HTMX

O conteúdo principal de cada painel é atualizado automaticamente a cada 60 segundos. As respostas HTMX retornam apenas o fragmento interno do dashboard, reduzindo HTML transferido e mantendo a navegação funcional sem JavaScript.

## URLs

- `/` e `/planner/`
- `/production/`
- `/purchasing/`
- `/inventory/`
- `/quality/`
- `/costing/`
- `/login/` e `/logout/`

A interface mantém links diretos para `/api/docs/` e `/admin/`.
