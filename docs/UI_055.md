# UI 0.5.5 — OEE e Andon

## Objetivo

Transformar os eventos já capturados pelo terminal da versão 0.5.4 em indicadores operacionais por máquina, sem duplicar apontamentos de produção.

## Dados mínimos da máquina

- `planned_minutes_per_day`: minutos programados de produção no dia;
- `ideal_cycle_seconds`: ciclo ideal por unidade para o cálculo de performance.

## Rastreabilidade do apontamento

Todo apontamento concluído pelo terminal cria um `MachineProductionRecord`, ligando `ProductionReport`, `WorkOrderOperation` e `Machine`. Apontamentos criados por outros canais continuam válidos, mas não entram no OEE por máquina até terem vínculo explícito.

## OEE

O snapshot diário `OEEPeriodSnapshot` persiste:

- minutos planejados;
- minutos de parada;
- minutos operacionais;
- quantidade boa;
- refugo;
- disponibilidade;
- performance;
- qualidade;
- OEE;
- número de falhas;
- MTBF;
- MTTR.

## Andon

Acesse `/shopfloor/andon/`. Cada cartão de máquina mostra estado atual, OP/operação, parada aberta, OEE, disponibilidade, performance, qualidade, produção boa, refugo, minutos de parada, falhas, MTBF e MTTR. A tela atualiza a cada 15 segundos com HTMX.

## Reprocessamento

```bash
python manage.py calculate_oee --plant SP01 --date 2026-08-07
```

O cálculo usa `update_or_create`, portanto pode ser reexecutado com segurança para o mesmo dia/máquina.
